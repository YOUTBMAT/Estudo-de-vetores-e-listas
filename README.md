## 📌 Sobre o Projeto

Este repositório foi estruturado para servir como um laboratório de testes e ambiente de **aprendizado focado em estruturas de dados lineares**, abordando a teoria e a prática por trás de **Vetores e Listas** utilizando a linguagem Python.

O entendimento de como conjuntos de dados são agrupados e manipulados de forma sequencial na memória é um dos conceitos divisores de águas na Ciência da Computação, servindo de base para o desenvolvimento de algoritmos eficientes.

### 🧠 Conceitos e Métodos Explorados:
- **Alocação Dinâmica:** Compreensão de como as listas em Python gerenciam dinamicamente o espaço em memória (diferente de vetores estáticos tradicionais).
- **Indexação e Fatiamento (`Slicing`):** Técnicas para acessar elementos específicos ou extrair subconjuntos de dados utilizando intervalos (`lista[inicio:fim:passo]`).
- **Métodos de Mutabilidade:** Manipulação interna de arrays utilizando funções nativas essenciais:
  - `.append()` — Inserção de novos elementos no final da estrutura.
  - `.insert()` — Adição de dados em posições e índices específicos.
  - `.pop()` e `.remove()` — Estratégias de exclusão de elementos por índice ou por valor.
  - `.sort()` — Ordenação e rearranjo de dados organizados.

---

## 📐 Base Teórica: Vetores Estáticos vs. Listas Dinâmicas

Em linguagens de mais baixo nível, um **vetor** possui tamanho fixo e imutável determinado na sua criação. Já em Python, a estrutura padrão de **lista** funciona como um array dinâmico (com redimensionamento automático sob o capô). 

Os experimentos deste repositório visam explorar o comportamento dessas coleções quando submetidas a loops de processamento, buscas lineares e manipulações de valores.
